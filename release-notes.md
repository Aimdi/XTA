## XTA — aimdi165

### aimdi149, unchanged

This build is the aimdi149 source exactly as released on 27 September. The only change is the version code, so it installs over aimdi164 in place and keeps your data. Nothing from aimdi150 to aimdi164 is in it.

### Installation

For most Android phones, use **`xta-aimdi165_arm64-v8a.apk`**. Universal, ARMv7
and x86_64 APKs are also supplied. The base version code is **400001340**, above
every aimdi164 variant. The app ID (`com.aimdi.xta`) and release signing identity
are unchanged for in-place updates.

The release workflow checks translations, skill synchronization, analysis and
the full Flutter test suite on the tagged source before building. It verifies
all four APK variants, versions and signing certificates before publication.
**`release-build.json`** and **`SHA256SUMS`** accompany the APKs.
