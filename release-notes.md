## XTA — aimdi169

### New icon

- The launcher icon is redrawn: the same two crossed loops forming an X, now in an even, cleaner line. It is built for every launcher shape, the round and rounded-square masks included, and for Android's themed (monochrome) icons.

Everything from aimdi168 is included: the profile filter chips and the diagnostic for saves that stop after adding someone to a group.

### Installation

For most Android phones, use **`xta-aimdi169_arm64-v8a.apk`**. Universal, ARMv7
and x86_64 APKs are also supplied. The base version code is **400001380**, above
every aimdi168 variant. The app ID (`com.aimdi.xta`) and release signing identity
are unchanged for in-place updates.

The release workflow checks translations, skill synchronization, analysis and
the full Flutter test suite on the tagged source before building.
**`release-build.json`** and **`SHA256SUMS`** accompany the APKs.
