# Settings and plugin direct access

Installed timeline plugins open their existing full-client route on tap and
through a labeled Open button. Keep the gear for configuration; move the
show-as-tab toggle into the overflow menu beside uninstall. Helpers without a
client remain configurable and never open an empty page.

Settings search indexes translated individual control labels and descriptions
across General, Posts, Media, Theme and Accessibility. Results show their parent
section, open that section and scroll to a highlighted control. Search routes
eagerly build their section only so a target below the fold can be found; normal
settings retain their existing layout and lazy list. Reuse controls and prefs.

Search feature state uses Store. Verify a deep target (autoplay / reading
position), a working toggle reached through search, and separate plugin Open
and Settings destinations. Keep the existing icons and localized labels.
