## 1. Per-feed appearance

Compact, Gallery, Reading presets and independent nullable overrides for counts, link previews, and fetched media. A source/native-ID JSON-pair identity separates feeds and survives restart. Missing overrides inherit existing source behavior, including Reddit's normal visible counts under Zen/Calm. Single-feed changes affect only that feed and do not replace its native controller or cached post state. The source picker, active tab identity, settings entry and native cards must all consume the same effective appearance. Hidden counters retain clearly named navigation/local actions. Disabling previews must not discard fetched Gallery media. UI reset removes the override. Bound persistence to 1000 identities / 2MB. Later mixes use the same identity and controls.

## 2. Explicit shared translation

Support disabled (default), DeepL, LibreTranslate and the existing AI backend. Persist provider, endpoint, API key and target language as secret preferences. Translate only after explicit action, across X, Mastodon, Bluesky, RSS and Substack articles and full Notes. Restore original text without changing original native content. Handle loading, cancellation/stale response, failure, retry, empty text, large paragraphs and provider changes. DeepL uses JSON authentication and `/v2/translate`; LibreTranslate uses JSON and preserves configured base paths. Retain URLs verbatim, paragraphs, words and Unicode surrogate pairs; chunk at 4000 UTF-16 units, input cap 400000, timeout 30 seconds. Bound secret cache to 32 entries / 500000 characters, keyed by content plus every configuration field. Article translation is distinct from the original WebView; native content warnings still govern visibility.

## 3. Actual-view history

Keep at most 500 bounded local post/article/profile entries, searchable in a dedicated screen and shared reader search. Record only a visible foreground current-route native surface after any content warning/filter is revealed; never record on fetch, offstage, hidden, navigation tap, or background. Enabled by default; disabling prevents new and queued records but retains entries; clear/remove erase without instantly recapturing the same mounted card. Rapid enable/disable and failed writes must honor the latest privacy intent. Store explicit fields only, no model/media/auth/translated JSON. Bounds: original text 2000, title 200, IDs/URLs 2048 UTF-16 units. Keep public query parameters including duplicates/order; strip userinfo, fragments and conventional credential parameters. Retain usable native IDs and navigate through native routes, original RSS offline keys/current follows, and retained excerpts when unavailable. Cover core X/Mastodon/Bluesky/Threads/Reddit/RSS/Substack and shared web/archive readers.

## 4. Shared filters

Shared ordered keyword and optional-regex rules with enable, case choice, timeline/search scope, hide/fold action and expiry. Patterns at most 256, matching text 32768, 100 rules, payload reads 200000, cache 256, pending 64. Arbitrary regex must run off the UI isolate in one owned worker with a 250ms deadline covering startup; kill/cancel generations on edits, expiry and disposal. A failed regex does not silently hide content or suppress independent valid keyword matches. Localized failure/reveal remains available. Native timeline/search/list/grid/group projection must remove hidden geometry and independent separators/chrome. Folded content retains accessible Show controls and native content-warning behavior. Newly pending hidden identities must not build/fetch media or enter history; only previously mounted children may be parked, and source removal/disposal releases them. Source-qualified stable keys are unique; mixes deduplicate before filtering. Suppressed automatic native media paging must resume from a genuine later user scroll or explicit retry without resetting native cells. Thread connectors and collection/card fold gates must reflect projected content.

## 5. RSS OPML

Import nested OPML outlines with xml 6.6.1 and export escaped XML, preserving actual feed URLs/titles. Accept predefined/numeric entities, reject external entities/DTD, malformed URLs including percent escapes, non-HTTP(S), and bounded excessive input/depth/outlines. Stream native PlatformFile imports with a 2MB bound before and during reading; handle cancel, invalid UTF-8, picker/read errors and empty/duplicate documents. Export via SharePlus.instance.share(ShareParams), with `.opml` fileNameOverrides. Show honest imported/duplicate/skipped and save/group-sync outcomes in native RSS settings and Reader Tools. Merge all existing follows, including pending initial load; serialize load/add/remove/import. Preserve old IDs/group membership. Query-significant collisions receive stable distinct new IDs based on normalized full URLs, keeping path case and raw query duplicates/order. Manual RSS add, native group helper and subscription add-box consume the actually stored ID. Mark RSS preferences secret before access. Failed canonical saves retain loaded state/table and restore the exact prior successful raw preference best effort; if both backend writes fail do not claim durable rollback. A saved preference plus failed transactional secondary table sync stays visible with explicit groups-pending retry.

## 6. Named native mixed feeds

Persist named definitions using source/native descriptors rather than widget closures. Add/edit/remove/reorder sources, survive restart, chronological or alternating order, and use each source's real client/cursor/card/navigation/content-warning/history/translation/filter behavior. Include X For You/following groups/list member posts; Mastodon local/federated/tag/following; Bluesky following/feed/list/author; RSS single/all-followed; usable Reddit timelines/subreddit and other existing native providers where configured APIs support them. X has no frozen native list-tweets method: label member posts, paginate all list members and per-query chunks (16), never claim native list ranking. Undated posts retain a stable fallback, not fabricated publication dates. Deduplicate native network/post identity (Mastodon includes origin); stable ties and fair alternating slots skip exhausted sources. Keep successful source snapshots on other-source refresh failure; errors/retry/paging remain source-specific. Invalidate old requests/cursors/private snapshots on source/auth/account/server/membership changes. Local name/order/appearance edits do not refetch or replace the scroll controller. Reuse native cards without nested Home chrome or duplicate fold gates. Wire both Home pickers, availability/body/options dispatch, Reader Tools and explicit mix appearance capability/name labels. No arbitrary credential/model disk cache is required.
